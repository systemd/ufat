# Hacking on ufat

ufat is built with meson and plain rustc. There is no cargo build and
there are no external crates.

## Requirements

- rustc 1.85 or newer. ufat has to keep building with rustc 1.85.
- meson 1.4 or newer and ninja.
- rustfmt, for the formatting check.

## Building

    meson setup build
    meson compile -C build

`meson compile` builds the library `build/src/libufat.rlib` and the
tests.

`RUSTC=` selects the compiler when the build directory is set up:

    RUSTC="rustup run 1.85.0 rustc" meson setup build-1.85

## Tests

    meson test -C build

`meson test` runs the unit tests of the library.

## Formatting

    meson compile -C build rustfmt
    meson test -C build --suite style

The code is formatted with rustfmt. rustfmt.toml sets the line width to
120 columns. The `rustfmt` target formats the code. The `style` test
suite checks the formatting. A plain `meson test` leaves it out.

## The case folding table

src/name/fold_table.rs is generated by tools/fold-table.rs. It holds the
upper case mappings of Unicode 16.0.0, the version rustc 1.85 ships. The
generator refuses to run with a compiler that ships another version, so
use a build directory set up with rustc 1.85:

    RUSTC="rustup run 1.85.0 rustc" meson setup build-1.85
    meson compile -C build-1.85 update-fold-table
    meson compile -C build-1.85 check-fold-table

`update-fold-table` regenerates the table. `check-fold-table` compares
it with a fresh one. Moving to another Unicode version changes which
names ufat tells apart. Do it on purpose and in a commit of its own.

## Exhaustive sweeps

    meson configure build -Dslow-tests=true
    meson test -C build --suite slow

tests/exhaustive.rs checks the layout computation, the time conversion
and the name handling over large ranges of inputs. It takes about a
minute on 16 cores. It is built and run only when the `slow-tests`
option is set.
